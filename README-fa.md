# AR-Links (اپ نصب‌شدنی)

## انتشار (یک بار)
**Netlify Drop (ساده‌ترین):** فایل zip را باز کنید، به app.netlify.com/drop بروید و پوشه‌ی باز‌شده را بکشید و رها کنید. آدرس https می‌دهد.
**GitHub Pages:** همه‌ی فایل‌ها را در یک مخزن بریزید → Settings → Pages → Deploy from branch.

## نصب روی گوشی
آدرس https را در Chrome باز کنید → منو → «Add to Home screen / افزودن به صفحه‌ی اصلی». دفعه‌ی بعد بدون اینترنت هم باز می‌شود.

## استفاده
1. «محدوده‌ها و لایه‌ها» → «محدوده‌ی جدید» (مثلاً لینک خط سه).
2. «افزودن لایه (فایل)» → GeoJSON / KML / SHP (به‌صورت ZIP) / DXF.
   - DXF: پهنه‌ی UTM را انتخاب کنید («تشخیص با GPS» کمک می‌کند) و لایه‌های DXF مورد نظر را تیک بزنید.
   - نوع لایه، رنگ و عمق را تعیین کنید.
3. «شروع AR با GPS» یا برای تست «شبیه‌سازی».
4. با «پشتیبان‌گیری» داده‌ها را به فایل JSON ببرید و روی گوشی دیگر «بازیابی» کنید.

GPKG و TIFF فعلاً پشتیبانی نمی‌شوند.

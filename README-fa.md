# AR-Links (اپ نصب‌شدنی)

## به‌روزرسانی روی GitHub
همه‌ی فایل‌های این پوشه را دوباره در مخزن بارگذاری کنید (فایل‌های هم‌نام جایگزین می‌شوند). بعد اپ را کامل ببندید و دو بار باز کنید. داده‌های قبلی حفظ می‌شود و داخل «پروژه‌ی ۱» می‌آید.

## ساختار
پروژه ← محدوده ← لایه. از «پروژه‌ها و لایه‌ها» پروژه و محدوده بسازید و برای هر لایه فایل (GeoJSON / KML / SHP در ZIP / DXF) بدهید.
برای هر لایه: روشن/خاموش، رنگ، عمق و ضخامت.

## دو نما
- نمای AR (دوربین)
- نمای پلان روی نقشه‌ی OpenStreetMap (نیاز به اینترنت برای کاشی‌های نقشه؛ خط‌ها و لایه‌ها بدون اینترنت هم کشیده می‌شوند)

## نکته‌های AR
- پیش‌فرض: لوله‌ها روی سطح زمین نشان داده می‌شوند. «نمایش در عمق واقعی» در ⚙ تنظیمات آن‌ها را زیر زمین می‌برد.
- دقت GPS گوشی ۳ تا ۱۰ متر (گاهی بیشتر) است. کنار یک منهول بایستید و «من روی نزدیک‌ترین نقطه‌ی نقشه ایستاده‌ام» را بزنید.
- اگر خط‌ها بالاتر یا پایین‌تر از زمین دیده شدند، «تصحیح شیب دوربین» و «زاویه‌ی دید» را تنظیم کنید.

GPKG و TIFF فعلاً پشتیبانی نمی‌شوند.
